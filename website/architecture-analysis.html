Executive Summary

Tea With God employs a sophisticated World Model Architecture combined with an Offline-First Design Pattern that positions it as a technically advanced mental wellness application. The World Model serves as the app's competitive moat - a local-first AI system that enables personalized healing journeys, proactive interventions, and cross-game insights while maintaining complete user privacy. This document analyzes the architectural decisions, their trade-offs, and the strategic benefits for both business growth and user outcomes.

1. Architecture Overview

The app is built on a layered architecture with the World Model as its intelligent core, enabling offline-first operation with optional cloud synchronization.

The World Model - 7 Dimensions of User State

Journey

Current day, streaks, completion rates

Emotional

Mood levels, distortions, resilience

Cognitive

Working memory, focus, reframing ability

Physical

Tension hotspots, breathing, body awareness

Behavioral

Time preferences, engagement patterns

Spiritual

Prayer engagement, scripture retention

Brain Games

Game progress, scores, unlocks

5. Technical Innovations

Moving Average Mood Tracking

Instead of raw mood values, the World Model uses exponential smoothing to prevent "mood whiplash" from single bad entries and show meaningful trends.

newValue = current * 0.7 + latestInput * 0.3

Three-Tier Inference Strategy

AI Inference Tiers ┌─────────────────────────────────────────┐ │ TIER 1: Rule-Based (Always Available) │ │ • Pattern matching, keywords │ │ • Instant, deterministic │ │ • Works 100% offline │ └─────────────────────────────────────────┘ │ ▼ (if device capable) ┌─────────────────────────────────────────┐ │ TIER 2: Small Language Model (Future) │ │ • On-device AI (llama.cpp/ONNX) │ │ • More nuanced analysis │ │ • Still works offline │ └─────────────────────────────────────────┘ │ ▼ (if online + high-stakes) ┌─────────────────────────────────────────┐ │ TIER 3: Cloud LLM (Future) │ │ • Complex reasoning │ │ • When accuracy critical │ │ • Graceful degradation if offline │ └─────────────────────────────────────────┘

Journal Encryption Model

Privacy Architecture User's Device: ┌─────────────────────────────────────────┐ │ Journal Entry (plaintext) │ │ ↓ │ │ XOR Encryption (random per-user key) │ │ ↓ │ │ Encrypted Entry (base64) │ │ ↓ │ │ AsyncStorage (local only) │ └─────────────────────────────────────────┘ Server: ┌─────────────────────────────────────────┐ │ Never receives journal content │ │ Only receives: mood score, distortion │ │ counts, engagement metrics │ └─────────────────────────────────────────┘

The encryption key is generated on first use and stored in SecureStore (iOS Keychain / Android Keystore). It never leaves the device.

8. Conclusion

The Tea With God architecture is a strategic asset, not just technical infrastructure. It enables:

This architecture transforms Tea With God from "a devotional app" into "an intelligent healing companion." The investment in World Model infrastructure pays dividends in user outcomes, business defensibility, and future expansion capability.
