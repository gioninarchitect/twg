Privacy-First Design

On-Device Encryption

Journal content encrypted with per-user keys stored in secure enclave. Even if storage is accessed, data is unreadable.

Local-First Storage

All sensitive data stays on device. Cloud sync is optional and user-initiated. No "phone home" behavior.

Zero Knowledge

Server never receives journal content. Only anonymized metrics for aggregate analytics. GDPR/POPIA compliant by design.

Technical Deep-Dive: Key Innovations

Moving Average Mood Tracking

Instead of raw mood values, the World Model uses exponential smoothing for more accurate emotional state tracking:

newValue = current × 0.7 + latestInput × 0.3
  • ✓
    Prevents "mood whiplash" from single bad entry
  • ✓
    Shows trends, not spikes
  • ✓
    More accurate picture of emotional state over time
  • ✓
    Enables meaningful healing trajectory calculation

Journal Encryption Model

Multi-layer security ensures journal content is protected at rest and never transmitted:

  • ✓
    Per-user encryption key - Generated on first use, stored in iOS Keychain / Android Keystore
  • ✓
    XOR encryption - Journal content encrypted before storage
  • ✓
    Base64 encoding - Encrypted content stored safely in AsyncStorage
  • ✓
    Server never sees content - Only mood scores, engagement metrics
